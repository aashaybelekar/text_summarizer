**Text Summarizer** is a complete machine learning project that fine-tunes and serves a state-of-the-art HuggingFace transformer model to summarize text. It features a modular training pipeline, a FastAPI backend for easy inference, and full CI/CD deployment workflows using GitHub Actions and AWS ECR.

## ✨ Features

- **End-to-End ML Pipeline:** Modular scripts handling Data Ingestion, Data Validation, Data Transformation, Model Training, and Model Evaluation.
- **State-of-the-Art NLP:** Powered by the `google/pegasus-cnn_dailymail` model and fine-tuned on the `samsum` dataset.
- **RESTful Inference API:** A FastAPI application that provides direct endpoints to trigger model training and generate text summaries.
- **Continuous Integration & Deployment (CI/CD):** Automated GitHub Actions workflow that lints code, runs tests, builds Docker images, and pushes to Amazon ECR for self-hosted deployment.
- **Containerized:** Fully Dockerized using Python 3.10 for highly reproducible environments.

## 🏁 Getting Started

Follow these instructions to set up the Text Summarizer project on your local machine.

### Prerequisites

Ensure you have the following installed:
- [Python](https://www.python.org/downloads/) (3.10+)
- [Docker](https://docs.docker.com/get-docker/) (optional, for containerized running)
- Git

### Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/aashaybelekar/text_summarizer.git
   cd text_summarizer
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install Dependencies:**
   Install the required Python packages from the requirements file:
   ```bash
   pip install -r requirements.txt
   ```

## ⚙️ Configuration

The pipeline relies on easily modifiable YAML files to manage paths, hyperparameters, and model selections:

* **`config/config.yaml`**: Manages directory paths for artifacts, datasets (like `samsum_dataset`), and the tokenizer/model name (`google/pegasus-cnn_dailymail`).
* **`params.yaml`**: Contains the training arguments such as `num_train_epochs`, `warmup_steps`, `per_device_train_batch_size`, and `weight_decay`.

## ▶️ Usage

### 1. Run the Pipeline Manually
You can execute the entire data pipeline and train the model locally by running the main execution script:
```bash
python main.py
```
This triggers the sequential stages: Data Ingestion -> Validation -> Transformation -> Model Training -> Evaluation.

### 2. Start the FastAPI Server
To serve the model and interact with the endpoints, start the FastAPI application:
```bash
python app.py
```
*The API will be available at `http://localhost:8080`.*

### 3. Run with Docker
Alternatively, you can build and run the provided Docker container:
```bash
docker build -t text_summarizer:latest .
docker run -d -p 8080:8080 text_summarizer:latest
```

## 🌐 API Endpoints

The FastAPI backend exposes the following endpoints:

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/` | Redirects to the auto-generated Swagger UI (`/docs`) for easy API testing. |
| `GET` | `/train` | Triggers the `main.py` pipeline to train the model from scratch and returns a success status. |
| `POST` | `/predict` | Accepts a `text` parameter and returns the summarized output generated by the fine-tuned Pegasus model. |
